# Architecture Decision Records

This directory documents the key architectural decisions made during the development of the Gondor Ecosystem. Each ADR follows the format: **Context → Decision → Consequences**.

ADRs are particularly valuable for Gondor because several decisions involve non-obvious tradeoffs in cryptography, distributed systems, and financial engineering that are not immediately apparent from the code alone.
